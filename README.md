# supermessage

A cross-platform Matrix chat client — iOS, Android, Windows, macOS, and Linux from a single codebase.

Stack: **Tauri 2 + matrix-rust-sdk (Rust core) + Svelte 5 + Framework7/Konsta skins**. See [docs/tech-stack.md](docs/tech-stack.md) for the full architecture, decisions, risks, and milestones.

supermessage is the **Communication layer (client)** of the Synthetic Organization suite (AgentPod + Kaambaan + Matrix + org control plane) — the human-facing, agent-aware Matrix client for a mixed human/AI-agent organization. See [docs/positioning.md](docs/positioning.md).
