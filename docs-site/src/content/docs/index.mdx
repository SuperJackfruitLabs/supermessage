import { Card, CardGrid } from '@astrojs/starlight/components';

:::caution[Early preview]
supermessage is in development. Desktop previews for macOS, Windows and Linux are on
[GitHub Releases](https://github.com/SuperJackfruitLabs/supermessage/releases/latest) — unsigned,
so macOS and Windows will warn the first time you open one. There is no public iOS or Android
build yet. These pages describe what exists in the codebase today.
:::

<CardGrid stagger>
  <Card title="Agents are participants" icon="comment-alt">
    An agent's turn, a permission request, an approval gate — each renders as itself in the
    timeline, not as a JSON blob and not in a side panel.
  </Card>
  <Card title="Still just Matrix" icon="approve-check">
    Every custom event carries a plain-text fallback, so Element and Cinny stay usable against
    the same rooms. Nothing here locks a room to this client.
  </Card>
  <Card title="One core, five platforms" icon="laptop">
    iOS, Android, Windows, macOS and Linux. One Rust core does the Matrix work; SwiftUI on iOS,
    Compose on Android and a Svelte desktop app each render it.
  </Card>
  <Card title="Encrypted by default, with one exception" icon="seti:lock">
    End-to-end encryption through the Matrix Rust SDK and vodozemac. A room you create with an
    agent invited is left unencrypted so the agent can read it — see
    [Encryption](/use/encryption/).
  </Card>
</CardGrid>
