# M0 Spine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Log in to a real account on `id.agentpod.dev`, sync it, render the room list and a room's timeline, and send and receive plaintext messages.

**Architecture:** The Matrix client lives entirely in the Rust core. `SyncService` drives Simplified Sliding Sync; `RoomListService` and `Timeline` expose state as `VectorDiff` streams, which the core projects into versioned DTO diffs and emits as Tauri events carrying per-channel sequence numbers. Svelte stores apply those diffs through one shared primitive that detects gaps and resyncs. The webview never sees an SDK type.

**Tech Stack:** Rust 1.95, Tauri 2, matrix-sdk 0.18, matrix-sdk-ui 0.18, tokio, keyring 4.1; Svelte 5 (runes), SvelteKit SPA, Tailwind v4, virtua, vitest.

**Spec:** `docs/superpowers/specs/2026-08-13-m0-spine-design.md`

## Global Constraints

- **Homeserver:** `https://id.agentpod.dev` — Synapse 1.152.0, spec ≤ v1.12. Only `m.login.password` is advertised. Do not implement OIDC; `/auth_metadata` returns 404.
- **TLS ordering:** `core::tls::install_ring_provider()` must run before *any* TLS is constructed, which includes every `Client` build. Never construct a `Client` in a test without calling it first.
- **No SDK types cross IPC.** Every value sent to the webview is a hand-written DTO in `core::dto`.
- **Diff vocabulary is complete, not a subset:** `Append`, `Clear`, `PushFront`, `PushBack`, `PopFront`, `PopBack`, `Insert`, `Set`, `Remove`, `Truncate`, `Reset` — all eleven, mirroring `eyeball_im::VectorDiff` 0.8.
- **Both SDK streams are batched:** they yield `Vec<VectorDiff<T>>`, not a single diff. One envelope carries the whole batch.
- **Licenses:** permissive (MIT/Apache-2.0/BSD) plus unmodified MPL-2.0. No GPL, AGPL, or LGPL.
- **Running the app:** `pnpm tauri dev` only. A bare `cargo run` loads `devUrl` with nothing serving it and every `invoke` fails.
- **Rust:** edition 2021, `cargo fmt` and `cargo clippy` clean before every commit.
- **Svelte:** Svelte 5 runes (`$state`, `$derived`, `$props`). Styling uses the `src/app.css` tokens — no hardcoded colors.

```rust
//! The error type crossing the IPC boundary.
//!
//! Variants exist so the webview can branch on failure kind (a wrong password
//! versus an unreachable server) without parsing prose.

use serde::{Serialize, Serializer};
use serde::ser::SerializeStruct;

#[derive(Debug, thiserror::Error)]
pub enum CoreError {
    #[error("{0}")]
    Auth(String),
    #[error("{0}")]
    Network(String),
    #[error("{0}")]
    Store(String),
    #[error("{0}")]
    Protocol(String),
    #[error("the core is not ready yet")]
    NotReady,
}

pub type CoreResult<T> = Result<T, CoreError>;

impl CoreError {
    pub fn kind(&self) -> &'static str {
        match self {
            Self::Auth(_) => "auth",
            Self::Network(_) => "network",
            Self::Store(_) => "store",
            Self::Protocol(_) => "protocol",
            Self::NotReady => "notReady",
        }
    }
}

impl Serialize for CoreError {
    fn serialize<S: Serializer>(&self, serializer: S) -> Result<S::Ok, S::Error> {
        let mut s = serializer.serialize_struct("CoreError", 2)?;
        s.serialize_field("kind", self.kind())?;
        s.serialize_field("message", &self.to_string())?;
        s.end()
    }
}
```

Add `pub mod error;` to `src-tauri/src/core/mod.rs`.
